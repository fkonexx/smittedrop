# SMITTEDROP — симулятор кейсів з живою дуеллю

Гра з відкриттям кейсів (10 цінових категорій, 10 колекцій, 60+ предметів + унікальні дропи)
і **справжньою дуеллю між двома реальними гравцями** через сервер (Node.js + Socket.IO).

## Як влаштована дуель

- Один гравець тисне **«Створити дуель»** → стає хостом, отримує **код кімнати** (напр. `AB12C`)
  і **посилання** (напр. `https://твій-сайт.onrender.com/?duel=AB12C`).
- Хост може або **надіслати посилання** другові (той просто відкриє його — код підставиться сам),
  або продиктувати **код**, який другий гравець вводить у полі «Приєднатися».
- Гравці можуть бути на різних пристроях/у різних місцях — грають окремо, кожен на своєму екрані.
- Хост обирає кейс і кількість раундів, обидва тиснуть «Я готовий» — і сервер сам чесно
  «крутить» однакові кейси для обох одночасно, показуючи дропи в реальному часі.
- У кого сума вартості випавших предметів вища — той забирає весь пул голди.

Локальний режим «Проти бота» лишився окремою вкладкою для розминки офлайн.

## Структура проєкту

```
case-duel/
├── server.js           ← Node.js сервер (Express + Socket.IO), керує кімнатами дуелей
├── package.json
└── public/
    ├── index.html       ← вся гра (кейси, інвентар, апгрейд, дуель)
    └── gameData.js       ← спільні дані (кейси/предмети/шанси) для клієнта і сервера
```

## Деплой: GitHub → Render (безкоштовно)

### 1. Завантаж код на GitHub
1. Створи новий репозиторій на https://github.com/new (наприклад `smittedrop`).
2. У теці проєкту виконай:
   ```bash
   git init
   git add .
   git commit -m "SMITTEDROP: кейси + дуель"
   git branch -M main
   git remote add origin https://github.com/ТВІЙ_НІК/smittedrop.git
   git push -u origin main
   ```

### 2. Розгорни на Render
1. Зайди на https://render.com, зареєструйся (можна через GitHub).
2. **New +** → **Web Service**.
3. Обери свій репозиторій `smittedrop`.
4. Налаштування:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free (достатньо для гри з друзями)
5. Натисни **Create Web Service** — за 1-2 хвилини Render дасть посилання типу
   `https://smittedrop.onrender.com`.

### 3. Готово
- Це посилання і є твій сайт. Відкривай його — там кейси, інвентар, апгрейд і дуель.
- Щоб зіграти дуель: один відкриває сайт, тисне «Створити дуель», надсилає посилання/код
  другові — той відкриває той самий сайт (посилання саме підставить код) і приєднується.

**Важливо (безкоштовний план Render):** сервер «засинає» після ~15 хв бездіяльності і
прокидається кілька секунд при першому заході — це нормально для безкоштовного тарифу.

## Локальний запуск (для тестів)
```bash
npm install
npm start
# відкрий http://localhost:3000
```

## Що можна змінити
- Кейси, ціни, шанси й предмети — усе в `public/gameData.js` (масиви `CASES` та `ITEMS`).
- Стартовий баланс і стартовий інвентар — функція `freshStart()` у `public/index.html`.
